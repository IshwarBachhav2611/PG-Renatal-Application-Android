# PG-Renatal-Application-Android (RoomBuddy)

RoomBuddy is an Android-based PG rental and booking application for students and working professionals.

## Features
- Search PGs by city and rent
- Booking request system
- PG owner management
- Map integration using OSMDroid
- SQLite offline storage

## Technologies Used
- Java
- XML
- SQLite
- Android Studio
- OSMDroid
